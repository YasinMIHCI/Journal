# Journal

App Android perso : réveils selon école/entreprise, synchro emploi du temps ADE,
suivi d'activités (piano, dessin) et journal quotidien.

Ouvrir le dossier dans Android Studio (**File > Open**), laisser Gradle synchroniser, lancer `app`.

Voir `CLAUDE.md` (technique) et `docs/SPEC.md` (fonctionnel).
